# OSA — Mission & Release Goal

## Current goal
Deliver a polished, accessible, interactive cinematic learning experience for the three-part OSA lecture series, then grow the platform in verified batches of 50 files.

## Definition of done
- Three connected chapters: AI capability, knowledge and power, human agency.
- Genuine branching choices that change later scenes and conclusions.
- Keyboard-accessible navigation, reduced-motion support, responsive layout, readable subtitles/transcript.
- Save and resume progress locally without requiring an account.
- Source notes distinguish evidence, interpretation, and forecast.
- Tests cover navigation, branching, progress persistence, and mobile layout.
- No fake claims that generated video, voice, or external APIs exist unless verified.

## Upload protocol
- Ship work in reviewable batches of up to 50 files.
- Keep each batch coherent, documented, and testable.
- Never commit secrets, `.env` files, API keys, user data, or generated binaries that cannot be validated.
- Validate the batch before pushing and record commit SHA plus changed paths.
