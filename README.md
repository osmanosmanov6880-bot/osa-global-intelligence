# OSA — Global AI Intelligence & Research Center

Interactive cinematic learning experience about artificial intelligence, knowledge and human agency.

## Run locally

Requires Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current repository scope

This repository is bootstrapped with a runnable Next.js interactive course experience. The larger production project archive and the existing Research Center codebase are separate local artifacts; they are not silently represented as uploaded here. Before production, run `npm run build`, review accessibility, add analytics only with consent, and configure deployment.

## Course

1. The intelligence shift — what AI does and where it fails.
2. The architecture of knowledge — access, incentives and power.
3. Human agency — practical strategy for working with AI.

## Editorial standard

AI-generated summaries are not peer review. Claims should link to primary sources, and uncertainty must remain visible.
