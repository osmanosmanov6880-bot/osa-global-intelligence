## Editorial rules
1. Treat model output as a claim, not as evidence.
2. Separate observed facts from interpretation and forecasts.
3. Do not treat benchmark performance as a guarantee of real-world reliability.
4. Do not infer that all jobs in an exposed occupation will disappear.
5. When using market, benchmark, or employment statistics, record the exact report edition, page/table, publication date, and definition.
6. Generated visual scenes must not be presented as documentary footage.
7. The current cinema UI is a text-led interactive experience. It contains no recorded voiceover, soundtrack, or video footage.
